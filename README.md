# CAPACITI Connect

Create a full-stack IT Support & Workplace Operations Platform for CAPACITI. Include a clean modern interface with three primary tabs: (1) IT Incident & Communications Generator: audience (Staff, Candidates, Management), incident type (Outage, Maintenance, Resolution), affected system, and editable ready-to-send professional email alerts. (2) Incident Notes & Post-Mortem Summarizer: paste raw terminal/chat logs and generate an Executive Summary, Root Cause Analysis (RCA), and structured Markdown Action Items table with Assignees and Priority. (3) Ticket Prioritization & Shift Planner: input support tickets and a 2–8 hour shift-duration slider, classify using ITIL priorities P1–P4, and output an hourly technician schedule. Include a persistent Responsible AI banner in the sidebar warning users never to enter credentials, passwords, or PII, and mandating human review. Use Lovable Cloud for persistent data and AI-backed generation.
